# OpenIncasso TPP

Piattaforma **AISP-ready** di riconciliazione tra fatture FattureinCloud (cessione kWh / energia) e movimenti bancari.

> **Non è una licenza Banca d'Italia.** Un TPP autorizzato richiede società, programma di attività, polizza RC, ICT/DORA e provvedimento dell'autorità (6–12 mesi). Questo repo è il prodotto software live.

## Cosa fa

- Porta ogni fattura sulle righe della riconciliazione bancaria
- Aggiorna il saldo progressivo a ogni movimento
- Matching automatico importo / data / causale
- Import CSV fatture e CSV CBI/SEPA
- Adapter FattureinCloud, TrueLayer, Fabrick, CBI Globe, Salt Edge
- Rail Stripe live `massimo.tech` (saldo disponibile 0,00 EUR al momento del deploy)
